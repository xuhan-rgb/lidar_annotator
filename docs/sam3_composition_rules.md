# SAM3 后处理与合成规则

提示词调试窗口的“类别提示词”页只编辑启用状态、名称和提示词。“后处理与合成规则”页统一编辑地面修正、类别减法和优先规则。有效修改自动保存到 `$XDG_CONFIG_HOME/lidar_annotator/recipe.json`，未设置该环境变量时使用 `~/.config/lidar_annotator/recipe.json`，无需选择文件。关闭窗口时立即保存未写入的有效修改；无效编辑会显示未保存原因，保留上次有效配置。重新打开工具时自动选用系统目录中的配置，内置默认配置保留不覆盖。调试运行仍使用当次配置快照。

## 执行顺序

1. 基础类别按候选得分竞争；无强实例支持的行人/车辆候选继续按既有规则忽略。
2. 按列表顺序执行优先规则。
3. 应用地面物体、地面补全、井盖及碎屑修正。
4. 按列表顺序执行类别减法。
5. 保留原有行人/车辆证据检查，未知像素置信度归零。

列表顺序有意义：后一条规则可以继续处理前一条产生的类别。不进行循环迭代。禁用类别不作为规则输出类别或减法候选。

## 优先规则

- **优先类别**：满足条件时写入的类别。
- **覆盖类别**：仅处理当前标签属于这些类别的像素，可包括未知 255。
- **使用证据**：类别候选得分；行人/车辆的强实例支持；或地面类的草地提示词证据。
- **生效条件**：命中即覆盖；得分不低于/高于原类别候选得分；或不低于/高于指定比较类别的最高候选得分。
- **最低像素得分**：加权像素证据得分，不是 SAM3 实例分数门槛。强实例证据仍沿用实例分数至少 0.7 的既有定义。

默认围栏与树干规则保留两者比较关系，行人/车辆比较各自的强实例证据，草地比较树冠/围栏，立柱比较原类别候选得分。

## 类别减法

从“原类别”当前占据的像素中，扣除被减类别的有效候选区域。可选择多个被减类别：

- **归入被减类别**：重叠像素归入候选得分最高的被减类别，同分时按类别 ID 从小到大选择。
- **设为未知 / ignore**：重叠像素标签为 255，置信度为 0。

屋顶候选继续使用既有 `roof` 或至少两个顶棚提示词共同支持的规则，并限制在建筑候选区域内。默认只有“建筑减去屋顶/屋檐，归入屋顶”一条规则；取消启用该规则后，不再从建筑中提取屋顶。

## 配置兼容性

规则保存在 JSON 的 `composition_rules` 字段，包含有序列表 `priorities` 和 `subtractions`。没有该字段的旧配置自动沿用既有规则。显式保存默认规则与旧流程的 mask、置信度保持一致。

调试窗口与正式 LMDB 语义生成共用 `compose_image_semantics`，规则不局限于预览。单条提示词测试展示原始提示词分割，不执行整套类别合成规则；查看规则效果需运行整套提示词。
