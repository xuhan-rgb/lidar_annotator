# SAM3 mask 与标签生成规则

后续数据按这套已确认的 ZGC 规则生成。机器可读配置为 [recipe.json](../tools/autolabel/zgc_mask_recipe_v1/recipe.json)，历史执行代码与策略文件保存在 `tools/autolabel/zgc_mask_recipe_v1/source_archive`，文件来源及 SHA256 在 `manifest.json` 中。

最终数据版本：`/mnt/data/02-Datasets/sam3_zgc_roof_union_20261013/labels`。新增数据使用独立输出目录，保留原图、原始类别 mask、置信度、点云标签、BEV 标签和来源哈希。

## 提示词与处理顺序

1. 生成基础语义类别：地面、行人、车辆、建筑、树冠、围栏/灌木、树干、立柱/电线。建筑保持 `building`、`wall`、`shed` 的现有基础组合。完整提示词、冲突处理和草地规则以配置中的 `base_semantics` 及基础阶段源代码为准。SAM3 候选实例门槛 0.25，mask 门槛 0.5，使用当前冻结权重和 CUDA bfloat16 推理。
2. 用 `object on the ground` 增补地面物体，实例门槛 0.40，仅替换地面 0 或未知 255，标为类别 8。保护已有行人、车辆和静态类别。
3. 补全地面：`paved ground`、`pavement`、`asphalt road`、`parking lot pavement` 各门槛 0.50，至少两个提示词共同支持同一像素，才将原地面/未知区域设为地面。
4. 井盖：`manhole cover` 门槛 0.70，在原地面、地面物体或未知区域内并入地面，保护其他类别。
5. 小碎屑：`small debris on the ground` 门槛 0.45。原类别 8 的连通区域至少 50% 被该提示词支持，整个区域并入地面。这是语义规则，尚未指定四足可跨越的物理高度阈值。
6. 屋顶/屋檐：保留原建筑候选，使用下面的并集规则。屋顶类别 9 已存在时保留；新补充仅从建筑类别 3 中分离，不改地面、行人、车辆、立柱或其他障碍物。

```text
R = roof 实例得分 ≥0.40 的掩码
C = 以下三个提示词中，至少两个得分 ≥0.65 且共同支持同一像素：
    overhanging roof / metal canopy / overhead metal canopy

新增屋顶 = 原建筑掩码 ∩ (R ∪ C)
最终屋顶 = 已有屋顶 ∪ 新增屋顶
最终建筑 = 原建筑掩码 − 新增屋顶
```

字面提示词 `eaves` 在已测试的问题帧中没有检出，最终配置不依赖它。不要退回仅 `roof` 的方案：它曾漏掉 000000、000012 的金属顶棚。历史阶段的多提示词屋檐分支是来源记录，最终采用上述并集规则。

## 点云、BEV 与训练数据

使用同帧保存的标定 `pixels_uv` 和 `visible` 将图像标签投影到点云，未知点置信度为 0。训练图像标签将 7/8 映射为 6，将 9 映射为 4；BEV/弱监督必须通过 `weak_targets(..., schema='zgc_image_teacher_seven_v2')` 重算并校验。

可视化仅显示 XY[-20,20)m。存储 BEV 为 320×320、0.25m/格，显示中间 `[80:240,80:240]` 的 160×160 区域。原始点坐标保留。送入当前模型训练前，将监督过滤到 `[-20,-20,-3,20,20,6)` 并重建训练标签，避免范围外点参与监督。

屋顶/屋檐映射为镂空占用类别 4，而不是地面。当前静态通行标签代码只让建筑/围栏/其他静态障碍类别阻塞地面监督；镂空类别不会直接生成通行地面，净空不足的结构仍需几何判断。

该入口是当前 ZGC 版本的补充分支，会复用已有基础标签和地面修正，已经完成的帧按来源与输出哈希恢复。它不是任意新数据的通用导入器。新数据需要提供图像/点云索引与标定，并为输入路径、帧数、输出目录适配 I/O；提示词、门槛、类别映射和处理规则沿用配置。

历史源代码快照保留各阶段的实际执行方式，用于复现和迁移。快照含原执行路径，不能直接把当前 ZGC 路径当成新数据路径运行。图像来源优先只读，写入新版本目录。

## 验证与完成条件

- 合成测试覆盖类别保护、至少两个顶棚提示词的共同支持、建筑交集、置信度保持、训练类别映射及 XY/BEV 可视化边界。
- 先验证问题帧 000000、000012、000017、000021、000221、000298、000411、000440；对新数据使用对应问题帧和随机抽取的对照帧，记录抽样方法，不用前 N 帧推断整体分布。
- 全量输出核对 mask、置信度、点云归档和来源哈希；回读标签并用实际训练读取器验证弱监督一致性。
- 颜色调整只重画 overlay 和图例，并验证 mask、置信度及训练归档哈希不变，不重启训练。
- 未明确请求现场 UI/截图检查时，不启动应用或读取新截图作视觉验证；标签一致性检查不等于人工真值精度。
